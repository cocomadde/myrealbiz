## ✅ 강세 요인 (Bull Case)

1. **트리플 역세권 초입지** — JR 총부쾌속선 후나바시역 도보 8~9분, 도쿄역까지 25분 직통. 케이세이선 2개 역도 도보 8분.
2. **열화경감등급 3급 취득** — 목조 법정내용연수(22년) 제약을 극복하여 **25~30년 장기 융자 유치 가능**.
3. **용적률 98.7% 소화** — 32.6평 대지에 9세대를 배치한 극한 효율 설계 (실적 용적률 157.94% / 법정 160%).
4. **중개수수료 전액 면제** — 매도자 직판으로 약 364만 엔의 초기비용 절감.
5. **풀옵션 신축 사양** — 오토록, 독립세면대 3점 분리, IH, 욕실건조기, 1층 방범셔터, 무료 인터넷.

## ⚠️ 약세 요인 (Bear Case)

1. **토지 선행 결제 리스크** — 토지 대금 5,780만 엔 선결제 후 준공 인도. 시공사 부도·공기 지연 리스크 매수인 부담.
2. **손익분기 가동률 91.0%** — 9세대 중 1세대 공실 시 즉시 월간 현금흐름 역마진.
3. **에비가와 저지대 침수 리스크** — 표고 2.0~3.6m, 0.5~3.0m 홍수 침수 상정구역 및 도쿄만 고조 영향권, 액상화 가능성.
4. **적산 괴리** — 금융기관 보수적 적산가 6,198만 엔(매매가의 57.1%)으로 수익환원 평가 미취급 은행 시 자기자금 폭증.
5. **LP가스 채택** — 도시가스 대비 입주자 광열비 부담 증가로 장기 거주 안정성 저하 요인.
