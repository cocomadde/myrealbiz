帳簿上税引前当期純利益の算定根拠および建物価格按分法:

  1. 公課証明書の固定資産税評価比率による厳格按分:
    • 松戸市公課証明書実測評価額：土地4筆合計 38,124,108円 (84.43%) vs 家屋1棟 7,032,406円 (15.57%)（合計45,156,514円）。
    • 物件売買価格9,400万円のうち建物按分価格：

$$94,000,000 \times \frac{7,032,406}{45,156,514} = 14,638,999\text{ 円 (15.57\%)} \quad (\text{土地按分価格: } 79,361,001\text{ 円})$$

  • 法定耐用年数経過鉄骨造の簡便法減価償却：34年 $\times 0.2 =$ 最低5.4年償却。
  • 年間減価償却費：$14,638,999 \div 5.4\text{年} = \mathbf{2,710,926\text{ 円/年}}$。
  1. 帳簿上税引前純利益的計算式（法人の全額利息損金算入）:
    • $\text{税引前純利益} = \text{年間総収入} - \text{運営経費(OPEX)} - \text{減価償却費} - \text{借入金支払利息}$
    • 法人保有のため、個人のような土地借入利息不算入規定はなく、支払利息の全額(100%)が損金算入されます。
    • auじぶん銀行借入8,930万円（2.5%、30年）の初年度ADS 4,234,116円の内訳：元金 2,024,711円 + 利息 2,209,405円。
    • 利益計算検証：

$$6,656,400\text{ (総収入)} - 1,435,629\text{ (実質OPEX)} - 2,710,926\text{ (減価償却)} - 2,209,405\text{ (利息)} = +\mathbf{300,440\text{ 円 (健全黒字)}}$$

  1. キャッシュフローと決算健全性の両立:
    • 手残りCF（税引前CF）は年間 +986,655円（月額 +8.22万円）の安定キャッシュイン。
    • 決算書上も +300,440円の黒字を着地させ、金融機関格付けでの赤字警告を回避しながら保有法人法人全体として税引前純利益 402.3万円、税引後CF 172.3万円の持続的成長基盤を確立します。
  1. 保有法人法人受入適格性 5大重要検証総合判定（ICR／DSCR／ROI／帳簿純利益／キャッシュフロー）:
    • ICR (インタレスト・カバレッジ・レシオ): 現況0.9倍（脆弱） -> 1.2倍へ+0.3倍大幅改善（単品2.4倍の利息支払能力により銀行融資の1.0倍安全域を突破）。
    • DSCR (元利金返済余裕率): 現況1.5倍 -> 1.4倍と健全域維持（推奨基準1.20倍を安定的にクリア）。
    • ROI (自己資本投資利回り): 現況3.83% -> 4.77%へ+0.94%p向上（単品CCR 7.66%の高効率資本回収を反映）。
    • 帳簿上税引前純利益: 年間372.2万円 -> 402.3万円へ+30.0万円純増（固定資産税評価厳格按分による271万円の減価償却費損金算入後も健全黒字を堅持）。
    • 実質キャッシュフロー (CF): 税引後手残り年間81.1万円 -> 172.3万円へ+91.2万円（2.12倍に爆増！）（月額+7.6万円の追加手残り純増）。
    • 追加寄与 (担保力/LTV): 固定資産税基準LTVが261.08%から207.67%へ-53.41%p劇的改善（土地担保比率90.8%の絶大寄与）。
    • 総合判定結論: 適格（優良受入対象） — ICR 1.2倍突破、ROI 4.77%向上、決算書黒字堅持、税引後CF 2.12倍爆増および担保力大幅改善により、保有法人法人の財務体質強化と次回融資枠拡大を同時に実現する最重要戦略資産と判定される。

1.4 事前確認必須5大項目 (Pre-Closing Checklist)#

  1. 🚨 飲用水（自家井戸水設備）の現状および上水道本管引き込み状況:
    • 本物件は飲用水として公共上水道ではなく井戸水ポンプを使用しています。定期水質検査結果表およびポンプ機器の交換履歴を確認する必要があります。また前面道路への市営上水道本管の埋設有無と引き込み工事費用（想定150万~300万円）を水道局に事前確認すべきです。
  2. 📐 境界非明示取引の条件精査および境界標の現況確認:
    • 概要書に「境界非明示」と記載があります。189.67坪の大型土地であるため、隣地境界標の有無、越境物の有無、現況測量図の交付可否を契約前に売主と交渉する必要があります。
  3. 💧 建物雨漏り・修繕履歴および屋根・外壁塗装の確認:
    • 1994年3月築（築32年）の亜鉛メッキ鋼板葺鉄骨造です。直近10~15年の外壁塗装、コーキング、共用廊下防水の履歴を管理会社に確認し、漏水リスクを検証します。
  4. 🔍 レントロール賃料とエイブル募集図面の整合性突合:
    • 募集図面記載の賃料（5.3万~6.0万円）とレントロールの月額（6.1万~7.5万円）の差異は、駐車場代（5,000~7,700円）および定額水道料（2,000~3,000円）の合算契約に起因することを確認します。
  5. 🔥 LPガス供給会社の無償貸与設備契約の確認:
    • プロパンガス供給会社との設備無償貸与（給湯器・エアコン等）契約の有無および解約違約金条項の承継条件を確認します。
